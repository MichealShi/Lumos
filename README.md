# Lumos Markdown

一个为 macOS 打造的 Markdown 编辑器：全语法兼容、实时预览、数学公式、流程图与代码高亮。

> 目前仅提供 macOS 版本（Apple Silicon / arm64），当前版本 **v1.4.2**。

## 功能特性

### 编辑与预览
- **三种视图**：仅编辑器（⌘1）、分屏预览（⌘2）、仅预览（⌘3）；分屏支持滚动同步与可拖动分隔条
- **CodeMirror 6 内核**：语法高亮、行号、括号匹配、Tab 缩进、多语言代码块识别
- **快捷格式化**：加粗 `⌘B`、斜体 `⌘I`、插入链接 `⌘K`；导出 HTML `⌘E`
- **查找与替换**：源码查找（⌘F）、查找替换（⌥⌘F，支持正则/大小写/全词匹配）；预览模式下查找渲染内容
- **专注写作**：专注模式（F8）淡化非当前段落，打字机模式（F9）光标行保持居中
- **拼写检查**：可在「编辑」菜单开关，状态自动记忆

### Markdown 语法
- **完整 CommonMark + GFM**：标题、列表、引用、代码块、删除线、自动链接等
- **表格增强**：合并单元格、无表头、多表体（markdown-it-multimd-table）
- **丰富扩展**：任务列表（可点击勾选并回写源码）、脚注、定义列表、上标/下标、删除线、高亮 `==...==`、缩写、emoji、提示块（tip / note / info / warning / danger）
- **数学公式**：KaTeX，支持 `$...$`、`$$...$$`、`\(...\)`、`\[...\]` 及 GitLab 风格
- **图表与代码**：Mermaid 流程图/时序图等，highlight.js 约百种语言代码高亮
- **目录生成**：正文输入 `[TOC]` 自动生成嵌套可点击目录，点击在预览内跳转

### 侧栏与导航
- **大纲侧栏**（⌘⇧L）：按标题层级生成，滚动时高亮当前章节，宽度可拖动
- **文件树侧栏**：列出当前目录的 Markdown 文件，点击在当前窗口切换；新建与系统打开仍开新窗口
- **章节锚点**：标题自动生成中文友好的锚点 ID，支持文内跳转

### 文件与导出
- **文件操作**：新建（⌘N）、打开（⌘O）、保存（⌘S）、另存为（⇧⌘S）、最近文档
- **系统整合**：Finder 中直接用 `.md` 打开（已注册文件关联）、拖拽文件到窗口打开
- **导出 HTML（⌘E）与 PDF（⇧⌘E）**：图片内联为 base64、CSS 完整内嵌，文件可独立分发不裂图；导出为全文完整内容
- **图片本地化**：粘贴或拖入图片自动保存到文档旁 `assets/` 目录并插入引用

### 可靠性与多窗口
- **自动保存与崩溃恢复**：编辑内容自动存草稿，意外退出后重新打开提示恢复；关闭时提示未保存内容
- **外部修改检测**：文件被其他程序改动时提示重新加载，避免覆盖他人改动
- **多窗口**：新建与系统打开文件在新窗口进行，不覆盖当前文档；各窗口位置/尺寸独立记忆
- **主题与状态**：明暗主题（⇧⌘T）、窗口状态与视图偏好自动记忆

## 技术栈

Electron 45 · Vite 8 · CodeMirror 6 · markdown-it 14 · KaTeX · Mermaid · highlight.js
