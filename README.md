# Lumos Markdown

一个为 macOS 打造的 Markdown 编辑器：全语法兼容、实时预览、数学公式、流程图与代码高亮。

> 目前仅提供 macOS 版本（Apple Silicon / arm64），当前版本 **v1.4.0**。

## 功能特性

- **实时分屏预览**：左侧编辑、右侧即时渲染，支持滚动同步与可拖动分隔条，可切换「编辑 / 分屏 / 预览」三种视图
- **完整 Markdown 语法**：基于 CommonMark + GFM，支持表格（含合并单元格）、任务列表（可点击勾选并回写源码）、脚注、定义列表、上/下标、删除线、高亮、emoji、自动链接等
- **扩展渲染**：KaTeX 数学公式（`$...$`、`$$...$$`、`\(...\)`、`\[...\]`）、Mermaid 图表、highlight.js 代码高亮、多种提示块（tip / note / info / warning / danger）
- **编辑体验**：CodeMirror 6 编辑器、语法高亮、明暗主题、快捷键格式化（`⌘B` / `⌘I` / `⌘K`）、字数与行号状态栏
- **文件操作**：新建 / 打开 / 保存 Markdown、导出独立 HTML / PDF、Finder 中直接用 `.md` 打开（已注册文件关联）、最近文档、窗口状态记忆
- **大纲侧栏**：按标题层级生成可点击大纲，滚动时高亮当前章节，支持拖动调整宽度（⌘⇧L 切换）
- **图片本地化**：粘贴或拖入图片自动保存到文档旁的 `assets/` 目录并插入引用
- **自动保存**：编辑内容自动存为草稿，崩溃或意外退出后重新打开会提示恢复
- **专注写作**：专注模式（F8）淡化非当前段落，打字机模式（F9）让光标行保持居中
- **文件树**：侧栏「文件」标签展示当前目录的 Markdown 文件，点击在当前窗口切换；新建与系统打开仍开新窗口
- **目录生成**：正文输入 `[TOC]` 自动生成嵌套可点击目录
- **可靠导出**：导出 HTML/PDF 时图片内联，文件可独立分发
- **安全编辑**：关闭时提示未保存、检测外部修改、崩溃草稿恢复、拼写检查开关
- **多窗口**：打开文件时默认进入预览视图，新建文档默认分屏；在已打开文件的窗口里新建或打开其他文件会自动开新窗口，不覆盖当前文档；预览区内容横向放不下时可滚动查看

## 技术栈

Electron 45 · Vite 8 · CodeMirror 6 · markdown-it 14 · KaTeX · Mermaid · highlight.js

## 本地开发

```bash
npm install
npm start          # 构建并启动
npm run build      # 仅构建渲染层
npm run dist       # 打包 macOS 应用
```

> 若从 WorkBuddy 等注入了 `ELECTRON_RUN_AS_NODE=1` 的环境启动，需先执行 `unset ELECTRON_RUN_AS_NODE`。
